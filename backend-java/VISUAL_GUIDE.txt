📝 ADDING NEW FEATURES
════════════════════════════════════════════════════════════════════════════════

Example: Add new endpoint /custom

1. Open: RepoGuardianController.java

2. Add method:
   ┌──────────────────────────────────────┐
   │ @GetMapping("/custom")               │
   │ public ResponseEntity<String> custom(│
   │     @RequestParam String param       │
   │ ) {                                  │
   │     return ResponseEntity.ok(        │
   │         "Hello " + param             │
   │     );                               │
   │ }                                    │
   └──────────────────────────────────────┘

3. Save (Ctrl+S) → Eclipse recompiles automatically
4. Restart app (Ctrl+F11)
5. Test: http://localhost:8000/custom?param=World
   → "Hello World" ✓

🐛 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

Problem: "Cannot find RepoGuardianApplication"
Solution: Right-click project → Maven → Update Project → F5 refresh

Problem: "Port 8000 already in use"
Solution: Change in application.properties: server.port=8001

Problem: "BUILD FAILURE"
Solution: Right-click → Maven → Update Project

Problem: "Slow to start first time"
Solution: Normal! Maven is downloading dependencies (~500MB)
         Second run will be fast!

Problem: Console shows "Caused by: FileNotFoundException"
Solution: Click Console, make sure it's the right one showing Spring logs
